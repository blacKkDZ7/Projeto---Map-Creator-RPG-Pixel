# Projeto - Map Creator RPG Pixel 🗺️

Editor de mapas de RPG no navegador, com estilo retrô/pixelado,
para criar cenários de fantasia, futuristas ou contemporâneos para jogar com amigos.

## Objetivo
Criar um site onde eu possa montar mapas juntando "tiles" (peças) numa grade.

## Plano
- [x] Fase 1: grade na tela e pintar células com clique
- [ ] Fase 2: vários tiles, apagar, salvar e carregar mapa
- [ ] Fase 3: temas e exportar como imagem
- [ ] Fase 4: visual 2.5D
